Generative AI was used in this project as a coding and drafting assistant. The tool was Claude Code (Anthropic), run inside VS Code on the project folder, so it could read the data, write and run code, and inspect the outputs. The table records each use, what the AI produced, and what the team changed and checked. The ideas, the choice of research question and every decision listed in Appendix B were made by the team; the AI proposed options and the team chose between them.

| Task | Prompt (summarised) | AI output | Team modification and verification |
|---|---|---|---|
| Planning | "This is the new project brief. The AI needs to be implemented and we need to plan for that." | A step-by-step plan mapped to the brief and the marking criteria | Team chose the data scope, spatial unit, per-crop budget and hotspot output; rejected a recommender and dropped XGBoost [check: name who reviewed the plan] |
| Data audit | "I've added the CAPRI data to the project." | Code to read the rasters, a coverage audit, and the finding that CAPRI's surplus is regional only | Team confirmed the finding against the CAPRI readme files and chose to build a per-crop budget with HaNi-Crop |
| Data pipeline | Implement the approved plan for extraction and the per-crop budget | `data_prep.py`, audit tables, detection of the HaNi 2017 step | [check: who re-ran the pipeline and spot-checked regional values] |
| Models and evaluation | Implement the models and blocked tests from the brief; later, "the marking criteria only ask for one model, fix accordingly" | `models.py`, `evaluate.py`, metric tables; first a five-model comparison, then reduced to the single constrained network | Team decided to deliver one model and checked that the criteria do not require a comparison [check: who reviewed the split logic and the constraint code] |
| Figures and results document | "Give the results in an additional document for a presentation" | `figures.py`, `build_results_document.py`, results document | [check: who checked each figure against the CSV values] |
| Report drafting | Draft the report against the marking criteria without AI-style writing | First draft of `report_text.md` with all numbers filled from results files | Section owners rewrote their sections, verified every citation and number, and resolved all marked checks [check: list owners and changes] |

Verification steps the team applied to all AI output: re-running the full pipeline from raw data; checking that every number in the report is read from `results/` by the build script; checking each reference against its source; and running `scripts/style_check.py`.
