# Development log: plan versus delivered

Each entry records what the proposal (20 September 2026) or the team brief (9 October 2026) specified, what was done, and why. This log is the evidence for the "plan followed or adapted" part of the final report.

| Date | Proposal / brief said | What we did | Why |
|---|---|---|---|
| 2026-10-13 | Proposal: Australian GRDC/CSIRO field trials (wheat, barley, canola) | Replaced with the CAPRI disaggregated dataset (EU26 + UK, 2000-2018), per the team brief | The team adopted the CAPRI-first brief. CAPRI gives crop areas, yields and a full soil-surface N budget on one consistent basis. |
| 2026-10-13 | Proposal: XGBoost yield model plus a search for the minimum N reaching a target yield | Replaced with the brief's comparison: independent crop-specific networks, a shared three-output network, and the same network with an N-budget constraint, all in PyTorch | The research question changed from recommending N to testing whether a mass-balance constraint improves accuracy and consistency. One architecture for every model isolates the effect of sharing and of the constraint. |
| 2026-10-13 | Proposal: per-scenario N recommendation for farmers | Replaced with a ranking of crop-region-years by yield and predicted surplus | The brief states that any fertiliser recommendation needs field validation, and regional CAPRI data is not field-trial data. |
| 2026-10-13 | Brief: optional soil and weather context | CAPRI-only first; ERA5-Land weather added as a second stage | Gets the full pipeline working on the primary source before aligning external grids. |
| 2026-10-19 | Brief: work at FSU or aggregate to NUTS2 if allocation noise is too high | NUTS2 (area-weighted aggregation of FSU values) | CAPRI is solved at NUTS2 and then spatially disaggregated, so FSU-level differences mostly reflect the allocation model. Neighbouring FSUs are near-copies, which would make leak-free spatial testing difficult. |
| 2026-10-19 | Brief: audit whether surplus can be assigned consistently to a crop | Audit result: CAPRI's N budget (NinSOI, NRET, SURSOI) is reported per ha of UAAR for the whole region, not per crop. We construct a per-crop budget from CAPRI yields and HaNi-Crop crop-specific N rates. | Required for the brief's per-crop outputs. The construction is documented so the per-crop surplus is not mistaken for a CAPRI value. |
| 2026-10-20 | Plan: rescale HaNi crop rates so the crops sum to CAPRI regional totals | Not possible: HaNi has no grassland and 7 of its 21 crop files were not available. HaNi rates are used directly, area-weighted to NUTS2 with CAPRI 1 km crop areas. | Rescaling needs every land use. HaNi's arable mineral N covers 75% of CAPRI's regional total (correlation 0.81 across regions), and the gap is largest where grassland or olives and vines dominate (Ireland 0.10, Netherlands 0.40, Greece 0.41). |
| 2026-10-20 | Data audit | Raw HaNi mineral N changes by more than 50% year on year in 27% of 2017 rows, against about 5% in other years. Mineral and manure N now use the HaNi crop-region level (mean over the 2000-2014 training years) scaled by CAPRI's annual regional series. | Removes HaNi's year-to-year noise and its 2017 step, which fell in the test period, without using test-year data. The CAPRI ratio also converts gross application to CAPRI's soil-surface boundary. |
| 2026-10-20 | Removal = yield x grain N content | Grain N content calibrated by non-negative least squares of CAPRI regional NRET on area x yield of all 35 CAPRI crops (R^2 = 0.99). Wheat (20.1 kg N/t) and barley (18.9) fall inside literature ranges; maize (24.1) and rapeseed (62.9) did not and use literature midpoints (14.0, 31.5). | Keeps removal consistent with CAPRI where the calibration is physical, and avoids absorbing collinear crops into two coefficients. |
| 2026-10-21 | HaNi-Crop README: contact the authors before publishing results | The team contacted the authors, who gave permission to use the dataset in this project | Required before using a dataset that is under peer review. The data itself stays out of the public repository. |
| 2026-10-23 | Input: region-crop mean yield over the fitting years | Removed. Test (same splits, five seeds, nothing else changed): with the input, yield error was 0.77 t/ha on later years and 1.49 t/ha on held-out countries; without it, 0.87 and 1.21. The final retrained model without it gave 0.85 and 1.22. Reusing the past average alone gives 0.76 and 1.76. | The input helped on later years but hurt on new countries: a held-out country has no history, so the input was filled with a crop-wide average that the model had learned not to trust. Dropping it makes the model learn regional differences itself and treat every region the same way. The cost is slightly lower accuracy than a region's own past average on later years, which the report states. |
| 2026-10-23 | Brief: compare independent per-crop networks, a shared network, and the shared network with a budget constraint, plus a budget-calculation baseline | Delivered one model, the shared network with the budget built in (yield and removal predicted, surplus calculated from the budget). The comparison models, the soft-penalty sweep and the baseline were removed from the code and the reports. | The assignment asks for one model and its marking criteria do not require comparisons. The constraint is justified by the physics of the budget, and its effect is verified by the residual check (largest residual about 0.00003 kg N/ha). |
| 2026-10-20 | Brief: location as an input | Region centroid latitude and longitude, not a country or region embedding | An embedding has no learned value for a country held out of training, so it would break the held-out-country test. |
| 2026-10-20 | Inputs | Added each region-crop's mean yield over the fitting years (leave-one-year-out for fitting rows; crop mean for held-out regions) | Without it the networks lost to the budget baseline, which uses exactly this history. Giving every model the same information makes the comparison fair. It uses past years only, but it correlates with yield at r = 0.95, so it is reported as flagged by the leakage check. Removed on 2026-10-23, see the entry above. |
| 2026-10-20 | Brief: test unseen crops if enough examples remain | Not run | The shared model has crop-specific output heads, which cannot predict a crop with no training rows. |
| 2026-10-20 | Model selection | The constraint strength and the model used for the hotspot ranking are chosen by one rule on the 2015-2016 validation years: the lowest validation error among models that break the budget in at most 5% of rows. This selected the hard constraint (M3b); the best soft setting was lambda = 10. Learning rate (0.001) and weight decay (0) were tuned on the same years. | A stated rule avoids choosing by test results. Superseded on 2026-10-23, when only this model was kept. |
| 2026-10-20 | Other budget terms per crop | Deposition = regional ATMOSD. Fixation = 4.5 kg N/ha, the intercept of regional BIOFIX on legume and grassland shares (free-living fixation). Residues = removal x regional CRESID/NRET. | CAPRI gives these per ha of UAAR only. Each choice uses CAPRI's own regional values instead of external coefficients. |
| 2026-10-19 | Data integrity | All seven CAPRI archives passed a CRC test (`zipfile.testzip`). The oversized entries shown by `unzip -l` for `fsucroparea_ha.zip` are a listing artefact. | Verified before extraction. |
